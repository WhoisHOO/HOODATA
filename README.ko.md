# HOODATA

**센서, 장치, 데이터 파일을 한 대시보드에서 지켜보고, 노이즈와 특이사항을 기록하고, 그것이 어떤 상황에서
일어나는지 찾아 줍니다.**

Windows 10/11 · 설치할 것 없음 · 모든 처리는 내 PC 안에서 · [Apache License 2.0](./LICENSE) ·
[English](./README.md)

> **개발 중입니다.** 아직 릴리스가 없습니다. 계획과 진행 상황은 [docs/ROADMAP.md](docs/ROADMAP.md)에, 특이사항을
> 찾는 방법과 그 성능은 [docs/METHODS.md](docs/METHODS.md)(영어)에 있습니다.

## 개발 버전 써 보기

1. **Code → Download ZIP**을 눌러 내려받습니다. 압축을 풀기 전에 ZIP 파일을 마우스 오른쪽 버튼으로 눌러
   **속성** → **차단 해제**를 체크하고 **확인**을 누릅니다(스마트 앱 컨트롤이 켜져 있으면 이렇게 해야 `start.bat`이
   실행됩니다).
2. 원하는 곳에 압축을 풀고 **`start.bat`**을 더블클릭합니다. 작은 HOODATA 창이 뜨고 브라우저에 대시보드가 열립니다.
   몇 초 안에 이 PC의 값(CPU, 메모리, 디스크, 네트워크, 배터리)이 나타납니다.
3. 데이터 파일을 보려면 **데이터 연결**에서 CSV 파일을 끌어다 놓습니다.

HOODATA는 창이 열려 있는 동안 데이터를 모읍니다. 데이터는 `start.bat` 옆의 `data` 폴더에만 저장되고, 이 폴더를
지우면 처음 상태로 돌아갑니다.

## 할 수 있게 될 일

- **모으기**: 이 PC의 상태값, CSV·엑셀 파일, 데이터로거가 계속 쓰는 폴더, HTTP나 MQTT로 보내는 장치, Modbus TCP
  장치, 시리얼 포트(아두이노, RS-485 Modbus RTU)에서 값을 받습니다.
- **보여 주기**: 채널마다 지금 값, 그래프, 상태를 보여 주는 실시간 대시보드와 기간별 통계.
- **기록하기**: 끊김, 튐, 수준 변화, 멈춤, 범위 밖, 노이즈 증가, 평소와 다른 값을 언제, 어디서, 얼마나, 왜 이상으로
  봤는지와 함께 기록합니다.
- **패턴 찾기**: 어떤 상황(시간대, 요일, 다른 센서의 상태, 바로 앞에 일어난 다른 특이사항)에서 특이사항이 평소보다
  몇 배 자주 오는지 찾습니다.

AI 모델이 아니라 이 저장소에서 직접 구현한 통계 방법을 쓰므로, 모든 결과에 그렇게 본 이유가 함께 나옵니다.
범용 엔진을 먼저 만들고, 분야별 버전(스마트팜, 양식장, 공장 설비)은 그 위에 프로필로 얹습니다.
